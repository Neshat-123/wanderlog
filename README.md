# Week 1 - Wanderlog

Wanderlog travel journal homepage created as part of the CodGen Week 1 Frontend Internship.

## About the Project

A responsive travel journal homepage designed to help users plan trips and explore destinations.

## Features

- Responsive navigation bar
- Travel planning form
- Your Trips section
- Japan trip itinerary
- Explore Destinations section
- Destination cards
- Call-to-action section
- Responsive mobile layout
- Semantic HTML5 structure

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design


## Week 2 – CRUD Functionality

Implemented full CRUD functionality for trip entries using JavaScript and localStorage.

### Features
- Create new trips
- View saved trips
- Edit existing trips
- Delete trips
- localStorage persistence
- Date validation
- Dynamic destination images
